# Session 1 Image Prompts

These prompt files are standalone prompts for ChatGPT image generation.
Each prompt targets a 16:9 workshop notebook image at 1672x941 px and is
intended to visually match the existing `img/session_0/` image style.

Important background direction used in every prompt:

- Use Riga Old City / Daugava / Baltic archive atmosphere as the background cue.
- Do not depict the National Library of Latvia building or any distorted version of
  its distinctive angular glass shape.
- Avoid readable generated text unless a prompt explicitly asks for simple symbolic UI.

Suggested workflow:

1. Paste one `.txt` prompt into ChatGPT image generation.
2. Save the accepted image using the matching `.png` filename implied by the prompt file.
3. Resize/crop final accepted images to 1672x941 px before inserting them into the notebook.
